# WOLFFIA — CO₂ capture dashboard

เว็บแสดงผลระบบดักจับ CO₂ 2 ขั้น (Wolffia → CaO จากเปลือกหอย) ดึงข้อมูลสดจาก Google Sheet
ไม่ต้องติดตั้งอะไร ไม่ต้อง build — เปิด `index.html` ได้เลย

---

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้า **WOLFFIA** (dashboard) — เดิมคือ `wolffia.html` |
| `system.html` | หน้า **System** — ผังระบบแบบสด |
| `history.html` | หน้า **History** — ตารางย้อนหลัง + CSV — เดิมคือ `graphs.html` |
| `data.js` | ตัวกลางข้อมูล: ดึงชีต, แปลง CSV, คำนวณ efficiency, ฟังก์ชันสถิติ |
| `charts.js` | การ์ดกราฟ 1 ตัวใช้ซ้ำทุกหน้า (แก้ชื่อ/เลขกราฟ, สไลเดอร์, trend, PNG) |
| `dashboard.js` / `system.js` / `history.js` | ตรรกะเฉพาะของแต่ละหน้า |
| `style.css` | สไตล์ทั้งเว็บ |
| `system.png` | รูปผังระบบเดิม (ใช้เป็นมุมมองสำรองในหน้า System) |

### สิ่งที่ตัดออกจากโค้ดเดิม
- **Bootstrap + jQuery + Popper** — ใช้แค่ navbar อย่างเดียว แต่โหลดสคริปต์ 3 ก้อน จึงเขียน nav เองด้วย CSS แทน
- **โค้ด boilerplate ซ้ำใน 3 ไฟล์ HTML** — เหลือ nav 6 บรรทัดต่อหน้า
- **`<canvas id="co2Chart">` ซ้ำกัน 3 อัน** ใน `wolffia.html` (id ซ้ำ → Chart.js จะวาดลงอันแรกอันเดียว กราฟอีก 2 อันจะว่าง)
- **`drawCO2(label, data)`** ใน `script.js` รับพารามิเตอร์ชื่อ `label` แต่ข้างในใช้ `labels` → อ้างตัวแปรผิด
- **การอ่านคอลัมน์แบบตายตัว** (`r[2]`, `r[5]`, `r[8]`) เปลี่ยนเป็นหาคอลัมน์จากชื่อหัวตาราง ถ้าย้ายคอลัมน์ในชีตเว็บก็ยังทำงาน
- **`id="temp"/"rh"` ที่ไม่มีอยู่จริงในหน้า** — ชีตนี้ไม่มีอุณหภูมิ/ความชื้น

## การตั้งค่าชีต (สำคัญ)

เบราว์เซอร์จะอ่านชีตได้ก็ต่อเมื่อชีตเปิดสาธารณะ เลือกอย่างใดอย่างหนึ่ง:

1. **Share → General access → Anyone with the link → Viewer** (ง่ายสุด ใช้ค่า default ในไฟล์ได้เลย)
2. **File → Share → Publish to web → เลือกชีต → CSV** แล้วเปิดเว็บด้วย
   `index.html?csv=<ลิงก์ CSV ที่ได้>`

เปลี่ยนชีต/แท็บโดยไม่ต้องแก้ไฟล์:
`index.html?sheet=<SHEET_ID>&gid=<GID>` และปรับรอบรีเฟรชด้วย `&refresh=30` (วินาที)

ค่าเริ่มต้นอยู่ในหัวไฟล์ `data.js`:

```js
const CONFIG = {
  sheetId: '1b-mKNEgtPI6Kokmx5v2GT12_ZkCequK5xW59_UDP0fY',
  gid: '554060351',
  refreshMs: 60000,     // อ่านชีตซ้ำทุก 60 วินาที
  staleMinutes: 30      // ไม่มีข้อมูลใหม่เกินนี้ = ถือว่า logger หลุด
};
```

ถ้าอินเทอร์เน็ตหรือสิทธิ์มีปัญหา เว็บจะขึ้นแถบสีแดงบอกสาเหตุ และยังกด **Open CSV file…**
เพื่อโหลดไฟล์ CSV ที่ดาวน์โหลดมาเองได้ (ใช้ตอนนำเสนอออฟไลน์ได้ดี)

## คอลัมน์ที่ใช้

อ่านจากหัวตาราง: `Date`, `Time`, `CO₂_1 (ppm)`, `CO₂_2 (ppm)`, `CO₂_3 (ppm)`
(ถ้าไม่พบหัวตาราง จะถอยไปใช้คอลัมน์ A–E ตามลำดับ)

คอลัมน์ efficiency ในชีตไม่ได้ถูกอ่าน แต่คำนวณใหม่ในเว็บด้วยสูตรเดียวกัน (ผลตรงกับชีตทุกแถวที่ตรวจสอบ):

```
CO₂ reduced   = CO₂_1 − CO₂_3
Wolffia (%)   = (CO₂_1 − CO₂_2) / CO₂_1 × 100
CaO (%)       = (CO₂_2 − CO₂_3) / CO₂_2 × 100
Overall (%)   = (CO₂_1 − CO₂_3) / CO₂_1 × 100
```

แถวที่มี timestamp ซ้ำ (logger เขียนซ้ำบางครั้ง เช่น 2:16:11 และ 8:06:13) จะถูกนับครั้งเดียว
และแถวที่อ่านค่าไม่ได้จะถูกข้าม

## ข้อควรรู้ก่อนใช้ตัวเลขไปเขียนบทความ

- **Forecast คือการต่อเส้นถดถอยเชิงเส้น (least squares) ออกไปข้างหน้า** ไม่ใช่แบบจำลองทางฟิสิกส์
  ใช้ดูแนวโน้มได้ แต่ไม่ควรอ้างเป็นค่าทำนายในบทความ ค่า R² แสดงไว้ใต้กราฟเพื่อให้เห็นว่าเส้นตรงอธิบายข้อมูลได้แค่ไหน
- **Smoothing เป็น moving average แบบกึ่งกลาง** (centered) เหมาะกับการดูรูปคลื่นกลางวัน–กลางคืน
  แต่ถ้าจะรายงานค่าจริง ให้ตั้ง Smoothing = off
- **เมื่อจุดข้อมูลเกินที่ตั้งไว้ กราฟจะเฉลี่ยเป็นช่วง (bucket average) ไม่ใช่การสุ่มทิ้ง** ค่าเฉลี่ยใน KPI
  และไฟล์ CSV ยังคำนวณจากข้อมูลดิบทุกแถวเสมอ
- **หน้า System: สถานะไฟ LED มาจากตารางเวลาที่ตั้งบนหน้าเว็บ ไม่ใช่ค่าที่วัดได้** เพราะชีตนี้ไม่มีคอลัมน์สถานะไฟ
  ส่วน pH / อุณหภูมิ / กำลังไฟ วาดไว้แบบจาง เพราะยังไม่มีคอลัมน์ในชีตนี้ — ถ้าเพิ่มคอลัมน์เมื่อไหร่บอกได้ เดี๋ยวต่อให้
